# DocuMind AI Reader

An independent starter project for an AI-powered PDF study assistant. It supports:
- Uploading a PDF and extracting selectable text
- Summarizing selected text
- Summarizing the whole PDF (long documents are chunked)
- Generating a 10-question quiz from the PDF
- Asking questions about the uploaded PDF

## Tech stack
- Frontend: React + Vite
- Backend: Node.js + Express
- PDF extraction: `pdf-parse`
- AI: Google Gemini API through a server-side REST call

## Requirements
- Node.js 18+
- npm
- A Gemini API key for real AI responses (the app still runs in demo mode without one)

## 1. Start the backend
Open a terminal in `backend/`:

```bash
npm install
```

Copy `.env.example` to `.env` and add your API key:

```env
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-2.5-flash
PORT=5000
```

Then run:

```bash
npm run dev
```

Backend runs at `http://localhost:5000`.

## 2. Start the frontend
Open a second terminal in `frontend/`:

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## How to use
1. Upload a text-based PDF.
2. Wait for the text extraction to finish.
3. Select a paragraph in the extracted text, then click **Summarize selection**.
4. Or choose **Summarize full PDF**, **Generate 10 questions**, or enter a question in **Ask your PDF**.

## Important notes
- This is a separate prototype; it does not connect to or modify your existing Smart Reader database or Supabase storage.
- The current prototype displays extracted PDF text rather than a page-perfect PDF viewer. A proper PDF.js viewer and page-level selection can be added after the workflow is validated.
- Scanned/image-only PDFs need OCR; this starter reports when little or no text can be extracted.
- Without `GEMINI_API_KEY`, the backend uses clearly labelled demo responses. Demo responses are not generated by an AI model. Add a key to enable real AI responses.
- Never expose your API key in frontend code. Keep it in `backend/.env`.
- For very long PDFs, chunking helps keep individual requests within model limits, but extremely large PDFs may still need more robust limits and background processing.
